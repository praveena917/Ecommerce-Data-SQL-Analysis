# SQL for Data Analysis - Ecommerce Dataset

## Project Overview

This project demonstrates the use of SQL for data analysis on an Ecommerce dataset. The objective is to extract meaningful insights using SQL queries and understand database operations such as filtering, sorting, aggregation, joins, subqueries, views, and indexing.

## Objective

* Learn SQL data analysis techniques.
* Perform data retrieval and filtering.
* Analyze sales and customer data.
* Create views and indexes for better query management.

## Tools Used

* DB Browser for SQLite
* SQL
* Ecommerce Dataset (CSV)

## Dataset Information

The dataset contains ecommerce transaction records with the following fields:

* InvoiceNo
* StockCode
* Description
* Quantity
* InvoiceDate
* UnitPrice
* CustomerID
* Country

## SQL Operations Performed

### Data Retrieval

* SELECT statements
* Filtering using WHERE clause
* Sorting using ORDER BY

### Aggregation

* COUNT()
* SUM()
* AVG()
* GROUP BY
* HAVING

### Joins

* INNER JOIN
* LEFT JOIN

### Advanced SQL

* Subqueries
* Views
* Indexes

## Sample Analyses

### Total Orders by Country

Used GROUP BY and COUNT() to calculate the number of orders placed from each country.

### Revenue Analysis

Calculated revenue using:

Revenue = Quantity × UnitPrice

### Average Product Price

Used AVG() to determine the average unit price of products.

### Customer Analysis

Used JOIN operations to combine customer information with transaction data.
